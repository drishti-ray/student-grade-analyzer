# Student Grade Analyzer – Project Statement

## 1. Problem Statement

Students usually have marks in different subjects, and calculating total marks, percentage, grade, and class average manually can take some time.

The Student Grade Analyzer is a simple Python program that helps store student marks and perform some basic calculations on them. The user can add student details, view the records, calculate a student's result, find the student with the highest marks, and calculate the class average.

The main purpose of this project is to make basic student performance analysis easier using Python.

## 2. Scope of the Project

This project is mainly focused on basic student performance analysis.

The program currently works with four subjects:

* Python
* Mathematics
* EVS
* English

The program can:

* Store student details and marks
* Display the student records
* Calculate total marks and percentage
* Assign a grade based on percentage
* Find the student with the highest total marks
* Calculate the average marks of the class

The data is stored only while the program is running. It does not use a database or any online storage.

## 3. Target Users

The project can be used by:

* Students who want to check their marks and grades
* Teachers for a simple demonstration of student performance
* Beginners who are learning Python programming

## 4. High-Level Features

The main features of the project are:

1. **Add Student** – Enter student ID, name and marks for all four subjects.
2. **Display Students** – View the student records stored in the program.
3. **Calculate Result** – Calculate total marks, percentage and grade for a student.
4. **Find Top Student** – Find the student who has the highest total marks.
5. **Calculate Class Average** – Calculate the average total marks of all students.
6. **Exit**s – Exit the program.
